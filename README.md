# RRB PO Prelims mock platform

A personal, offline-first mock-test app for IBPS RRB PO (Officer Scale-I) Prelims. It runs in the browser with no
backend and no login. Everything is stored in IndexedDB.

**Live site: https://ritik650.github.io/rrb-mock-platform/**

Unofficial practice tool, not affiliated with IBPS. The questions are original and generated by the tool in this repo.

## Use it

Open the live site and install it from the browser's address bar. It works offline after the first load. Your attempts
stay in that browser on that device, so use **Settings > Export attempts** to move them or keep a copy.

## Develop

    npm install
    npm run dev        # http://localhost:5173
    npm test           # unit and integration tests
    npm run typecheck

    npm run build      # the production build, which is the one that works offline
    npm run preview    # http://localhost:4173

Pushing to `main` runs the tests and, if they pass, deploys to GitHub Pages.

## Add more mocks

Generate them with the tool in `rrb_mock_generator/`, then use **Import JSON** on the Mocks page. Files must match the
format in `src/types.ts`. Mocks are de-duplicated by `mock_no`, and a file with a problem is rejected whole, with a list
of what to fix.

## Back up your attempts

Attempts live only in this browser's storage, so clearing site data deletes them. Use **Settings > Export attempts** to
keep a copy.

## Exam behaviour worth knowing

- **Selections are drafts, as on the real console.** An answer counts only after Save & Next or Mark for Review & Next.
  Moving away any other way discards it, and this includes Next, Previous, the palette and a section tab. The screen
  warns you while a selection is unsaved. An unsaved selection also does not count when you submit or when time runs out.
- **Keyboard:** 1-5 or A-E choose an option, N is Save & Next, M is Mark & Next, ← and → navigate, and **Shift+C** is
  Clear Response. Plain C is option (c), so that a stray keypress cannot wipe a saved answer.
- **The clock runs only while the test is open.** Closing the tab freezes it, and reopening resumes from the time left.

## How the analysis is worked out

- **Average time** is all your time in a topic divided by the questions you answered there, so a long read you abandoned
  still counts against you. If you answered none, it divides by the questions you spent time on.
- **Suggested attempt order** ranks topics by expected marks per minute across all finished attempts:
  (accuracy × 1 − (1 − accuracy) × 0.25) ÷ your minutes per question. Topics with no history assume 70% accuracy at
  target time.
- **Topic drills** rank a question by its latest answer: wrong first, then never seen, then skipped, then correct.

## Where things are

| Path | What it holds |
|---|---|
| `src/lib/` | Pure rules: timer, palette states, scoring, analysis, drills, the visibility rule |
| `src/lib/visibility.ts` | The single gate that keeps answers off the test screen |

| `src/components/visuals/` | Inline SVG renderers for every visual type |
| `src/components/exam/` | The test screen |
| `src/components/review/` | The solutions screen |
| `data/` | The question bank loaded on first run |
